# Agent 学习日志 Demo14

## Demo14：意图分类架构 + 多工具扩展

### 学习内容
1. **意图分类架构**：在代码层对用户提问进行意图识别（时间查询/数学计算/联网搜索/知识库问答），不同意图走不同的处理流程和prompt模板，解决"一个大prompt包打天下"导致的规则冲突、维护困难问题。
2. **多工具扩展**：在现有时间工具基础上，新增计算器工具（eval执行数学表达式，字符白名单校验防止注入）和联网搜索工具（duckduckgo-search库，无需API key）。
3. **检索为空自动降级**：知识库问答模式下，若检索结果为空，自动切换至闲聊模式，放开模型使用自身常识回答，避免无意义的"知识库中没有相关信息"回复。
4. **工程设计思想**：
   - 知识库模式与闲聊模式分别构建prompt函数，因二者约束规则相反，分离后互不干扰
   - 滑动窗口截取与历史格式化分离，截取函数返回结构化列表，格式化在调用层完成，遵循数据与展示分离原则

### 实操踩坑与解决方案
1. **ImportError: cannot import name 'classify_intent'**
   - 原因：tool_router.py未替换为新版，仍为仅时间工具的旧版本
   - 解决：完整替换tool_router.py，确认包含classify_intent、run_tools、calculate、web_search等函数
2. **联网搜索TLS握手失败**
   - 现象：duckduckgo-search库内部调用Bing搜索，国内网络环境下报`peer misbehaved: SelectedUnofferedKxGroup`
   - 解决：联网搜索为附加功能，暂不影响核心流程，先搁置，后续更换更稳定的搜索服务（如SerpAPI）
