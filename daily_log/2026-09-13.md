# 2026-09-13 学习打卡
# Demo18 + Demo19 Web界面 + 知识库管理

## Demo18：流式Web界面
1. **Gradio框架**：用Python的Gradio库，几行代码把命令行程序变成可视化网页聊天界面，不用写HTML/CSS/JS。
2. **gr.ChatInterface**：Gradio自带的聊天界面组件，自动生成输入框、对话气泡、清空按钮。
3. **yield流式输出**：Gradio的生成器函数用yield逐字返回，网页上自动逐字显示，和命令行效果一样。
4. **自动保存**：每轮对话回答完自动保存，关网页不用输exit。

## Demo19：知识库管理
1. **gr.Blocks多Tab布局**：把界面分成"聊天"和"知识库管理"两个选项卡，功能分开。
2. **文件上传**：gr.File组件支持拖入txt文件，自动读取内容、转向量、存入知识库。
3. **知识库管理操作**：网页上查看当前知识库有哪些文档、上传新文档、删除指定来源文档，不用再手动改文件+跑build脚本。
4. **按钮事件绑定**：按钮.click()绑定函数，点按钮自动执行操作并刷新界面。

## 踩坑与解决
- **pip安装超时**：国内网络连不上pypi官方源，用清华/阿里镜像源解决。
- **gr.ChatInterface版本兼容**：旧版gradio不支持type="messages"参数，去掉即可。
- **VS Code文件缓存**：外部程序更新文件后，VS Code打开的旧标签不会自动刷新，需要关闭重开。
- **工作目录编码**：PowerShell读UTF-8文件显示乱码是正常现象，文件本身没问题。
