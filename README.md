# agent-learning-daily-log
用来记录每日 Agent 学习打卡、代码练习、踩坑日志
## 仓库结构
├── daily_log # 按日期划分每日打卡日志
├── log_creator.py # 一键生成当日打卡 md 的脚本
├── .gitignore # 屏蔽不需要上传的缓存、密钥文件
├── LICENSE # MIT 开源协议
└── README.md # 仓库说明文档
## 使用方法
1. 运行log_creator.py，自动生成当天打卡文档；
2. 在生成的md文件内填写学习内容、问题、规划；
3. VS Code提交推送，完成每日归档。

## 学习主线
1. 核心：Python + LangChain 开发AI Agent智能体
2. 兜底：Python后端开发（FastAPI）
