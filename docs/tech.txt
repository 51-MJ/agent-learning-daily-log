# Python编程知识

## Python基础
Python是一种高级、解释型、通用编程语言，以简洁易读的语法著称，被称为"胶水语言"。Python的设计哲学是"优雅、明确、简单"，强调代码的可读性。

Python的核心数据类型：
1. 数字类型：int（整数）、float（浮点数）、complex（复数）
2. 字符串：str，用单引号或双引号包裹，支持切片、拼接、格式化
3. 列表：list，有序可变序列，用[]包裹，支持增删改查
4. 元组：tuple，有序不可变序列，用()包裹
5. 字典：dict，键值对集合，用{}包裹，键唯一
6. 集合：set，无序不重复元素集合

## 函数
函数是组织好的、可重复使用的代码块，用于执行特定任务。
定义函数用def关键字：
def 函数名(参数1, 参数2=默认值):
    函数体
    return 返回值

函数参数类型：
1. 位置参数：按顺序传递
2. 默认参数：有默认值，调用时可省略
3. 关键字参数：调用时用参数名=值的方式传递
4. 可变参数：*args接收任意多个位置参数，**kwargs接收任意多个关键字参数

## 模块和包
模块是包含Python代码的.py文件，包是包含多个模块的目录（必须有__init__.py文件）。
导入模块的方式：
- import 模块名
- from 模块名 import 函数名/类名
- from 模块名 import * （不推荐）

## 面向对象
Python是面向对象语言，支持类、继承、多态。
类的定义：
class 类名:
    def __init__(self, 参数):  # 构造函数
        self.属性 = 参数
    def 方法名(self):
        方法体

继承：class 子类名(父类名):
子类可以继承父类的属性和方法，也可以重写父类方法。

## 文件操作
打开文件用open()函数：with open(文件路径, 模式, encoding="utf-8") as f:
模式：
- "r"：只读（默认）
- "w"：写入，会覆盖原有内容
- "a"：追加，在文件末尾添加
- "rb"/"wb"：二进制读写

读取方法：f.read()读全部，f.readline()读一行，f.readlines()读所有行存列表
写入方法：f.write(字符串)，f.writelines(字符串列表)

## 异常处理
用try-except捕获异常：
try:
    可能出错的代码
except 异常类型 as e:
    出错后的处理
else:
    没出错时执行
finally:
    无论是否出错都执行

常见异常：ZeroDivisionError（除零）、TypeError（类型错误）、ValueError（值错误）、FileNotFoundError（文件不存在）、KeyError（字典键不存在）、IndexError（列表索引越界）

## JSON处理
JSON是一种轻量级数据交换格式，Python内置json模块处理。
- json.dumps(数据)：Python对象转JSON字符串
- json.loads(字符串)：JSON字符串转Python对象
- json.dump(数据, 文件对象)：写入JSON文件
- json.load(文件对象)：读取JSON文件

# AI Agent开发知识

## 什么是Agent
AI Agent是一种能自主感知环境、做出决策并执行动作的智能体。一个完整的Agent通常包含：大语言模型（大脑）、记忆模块、工具调用、规划能力。

## RAG（检索增强生成）
RAG是一种结合信息检索和大模型生成的技术，解决大模型知识过时和幻觉问题。
RAG流程：
1. 文档加载：读取原始文档
2. 文本分块：把长文档切成小段
3. 向量化：用嵌入模型把文本转成向量
4. 存储：存入向量数据库
5. 检索：用户提问时，把问题转向量，在向量库中匹配相似片段
6. 生成：把检索到的片段和用户问题一起送给大模型，生成回答

## 向量数据库
向量数据库专门存储高维向量，支持相似度检索。常见的向量数据库：Chroma、FAISS、Milvus、Pinecone、Weaviate。
Chroma是轻量级本地向量数据库，适合学习和小型项目，支持持久化存储和元数据过滤。

## 嵌入模型
嵌入模型把文本转换成高维数字向量，语义相近的文本向量距离也近。常见的嵌入模型：OpenAI text-embedding-ada-002、BGE系列、nomic-embed-text、m3e。
nomic-embed-text是开源嵌入模型，可以本地运行，适合学习使用。

## 记忆机制
Agent的记忆分为短期记忆和长期记忆：
- 短期记忆：对话上下文，存在内存中，受上下文窗口限制
- 长期记忆：持久化存储，存在数据库或文件中，需要时检索召回
滑动窗口是一种简单的短期记忆优化方式，只保留最近N轮对话，控制上下文长度。

## 工具调用
工具调用让大模型能够调用外部函数获取信息或执行操作，突破纯文本生成的限制。
工具调用流程：模型判断需要调用工具 → 输出工具名和参数 → 系统执行工具 → 把结果返回给模型 → 模型生成最终回答。
